# 落日后残波：三套完整中文文案方案

基于 `bluetooth-wifi-chat` 分支，供选风格与逐项审阅。三列各自构成一套完整方案，可以从上到下单独阅读。

范围：当前 Flutter 应用 `lib/l10n/app_strings.dart` 的全部 124 项文案，以及应用系统名称、Android 常驻通知、iOS 权限用途说明。最后另列现有流程需要补齐的错误和状态文案，明确标注接入条件。内部诊断日志、协议字段和历史原生工程不属于这次界面文案方案。

`{name}`、`{count}`、`{max}`、`{host}`、`{target}`、`{ver}`、`{msg}`、`{current}` 是原有动态值，不是待补文案。表格中的 `<br>` 表示换行。

## 三种风格

| | A · 简洁直接 | B · 温和自然 | C · 无线频道 |
| --- | --- | --- | --- |
| 语气 | 短、清楚，接近日常应用 | 有一点落日和交谈的温度，操作仍直接 | 像一款轻量无线通信工具，简短利落 |
| Wi-Fi 模式 | Wi-Fi 聊天 | Wi-Fi 畅聊 | Wi-Fi 频道 |
| 蓝牙模式 | 蓝牙聊天 | 蓝牙对讲 | 蓝牙频道 |
| 会话称呼 | 聊天 | 聊天、聊天室 | 频道 |
| 文字区域 | 消息 | 消息 | 频道消息 |
| 首页副句 | 想说的话，就和身边的人说。 | 夕阳落下，话还没说完。 | 声音和文字，就在附近传递。 |

三套方案都把 Wi-Fi、蓝牙放进模式主名称。创建按钮和默认会话名称继续显示连接方式。两种模式均支持文字消息；Wi-Fi 支持自由通话，蓝牙按住说话。

“发送”“取消”“扬声器”等常用词允许三套相同。风格差异主要落在首页、会话命名、空状态和普通提示上。
