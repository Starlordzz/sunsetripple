# 故障排查

按症状分类。每条都先给最可能的原因，再给验证方法。

## 建不了房 / 搜不到设备

### 权限没给全

这是最常见的原因。应用在 `MainActivity.kt` 里一次性申请运行时权限，需要的项随 Android 版本变化：

| 权限 | 适用版本 |
| --- | --- |
| 麦克风 `RECORD_AUDIO` | 所有版本 |
| 蓝牙 `BLUETOOTH_CONNECT` / `BLUETOOTH_SCAN` / `BLUETOOTH_ADVERTISE` | Android 12+（API 31+） |
| `NEARBY_WIFI_DEVICES` + 通知 `POST_NOTIFICATIONS` | Android 13+（API 33+） |
| 精确定位 `ACCESS_FINE_LOCATION` | Android 13 以下（API 32 及以下） |

要点：

- **精确定位不能只给「大致位置」**——只给粗略定位仍会被拦截。
- **Android 13+ 建议授予通知权限**——没有它，前台通话服务的常驻通知不显示，服务也更容易被系统回收。
- 部分系统即使给了精确定位权限，还要求系统层的「定位服务」开关处于打开状态，才能扫描到 WiFi / 蓝牙设备。这是系统的限制，与本应用无关。

应用内的拒绝提示会指明缺哪一项，照着开即可。

### WiFi 房搜不到 / 直连失败

- 确认设备支持 WiFi Direct（P2P），少数定制系统会阉割这个能力。
- 关掉可能抢占 P2P 通道的功能：热点、投屏、WiFi 直连文件互传（如各家的「互传」）。
- 部分机型省电模式会限制 P2P，先关省电模式再试。
- Wi-Fi Direct 直连需要系统建立连接，应用会等待约 15 秒；超时会返回失败，靠近对方再试。
- 若一直失败，关掉 WiFi 再打开，重试一次。

### 蓝牙房搜不到房主

- 蓝牙房需要 **Android 10（API 29）及以上**，且设备支持 BLE。低版本会在开启时直接给出原因。
- 确认蓝牙已开启、蓝牙权限已授予。
- 房主需保持房间开启；扫描结果约 6 秒内没再出现就会从列表消失，重新「看看附近」即可。
- 蓝牙房不需要先在系统设置里配对。

## 连上了但没声音

### 先检查本机音频

当前版本没有回环自测功能，请按下面逐项确认：

- 麦克风权限是否已授予（`RECORD_AUDIO`）。
- 麦克风是否被其他应用占用（录音、来电、语音助手等）。
- 是否误触静音；外放 / 听筒音量是否调高。
- 对端设备是否静音。

### 蓝牙房：忘了按住说话

蓝牙房是**按住说话（PTT）**，不是全双工。按住中间圆盘才发送，松手即收听。

另外，按住 PTT 期间本机播放静音——听不到别人是**正常行为**，为的是避免回声。松手后即可听到。

## 频繁掉线 / 重连

### 距离与遮挡

- WiFi Direct：空旷环境数十米，隔墙衰减明显。
- 蓝牙：约 10 米，且身体遮挡就会显著影响。

把设备从口袋里拿出来，避免用身体挡在两台设备之间。

### 重连行为是什么样的

WiFi 房断线后会按 **1 秒 → 2 秒 → 4 秒**重试三次（`ReconnectController`）。

- **重连成功** → 凭 16 字节会话令牌恢复原成员号与入房顺序，无需重新加入。
- **三次耗尽** → 若本机缓存了房主交接快照，会按快照自动接管（WiFi 房）；否则退出房间。

蓝牙房当前没有独立的自动重连接口，链路断开后需要重新搜索并加入。

### 系统杀后台

前台服务与组播锁已经尽力保活，但国内厂商的系统各有各的激进策略。若通话经常被无故中断：

1. 在系统设置里给应用加**电池优化白名单** / 「允许后台运行」。
2. 关闭针对本应用的「自动管理」或「智能省电」。
3. 在最近任务列表里**锁定**本应用。

### 房主换人了

房主离开或失联时，WiFi 房会按快照自动选举继任者并重建，语音短暂中断，之后自动恢复。**蓝牙房不支持房主转移**，房主退出即散会。详见 [房主转移机制](房主转移机制.md)。

## 音质问题

### 声音断续 / 卡顿

抖动缓冲的策略是**宁可丢，不可等**：迟到的包直接丢弃，丢包位置交给 Opus PLC 补偿。所以链路质量差时表现为轻微的断续而不是延迟累积。

改善方法：缩短距离、减少遮挡、避开 2.4 GHz 拥挤环境（微波炉、大量 WiFi 设备）。

### 蓝牙房音质明显不如 WiFi 房

这是设计使然。蓝牙房码率 16 kbps，WiFi 房 24 kbps；且蓝牙房音频要经房主转发，多一次编解码。

### 有回声

- Android 使用 `VOICE_COMMUNICATION` 采集并启用硬件的回声消除（AEC）/ 降噪（NS）/ 自动增益（AGC），iOS 使用 VoiceProcessingIO；部分机型没有硬件 AEC。
- 降低外放音量，或改用耳机。
- 两台设备离得太近（一米内）时，外放会直接串到对方麦克风，这不是软件能解决的。

## 诊断报告

在「关于」页可以生成并复制诊断报告。报告会做脱敏处理：MAC、IPv4 和长令牌会被替换为占位符。报告只反映当前状态，不落盘、不持久化，也不会自动上传。

## 安装问题

### 提示「应用未安装」或「包冲突」

当前包名是 `host.msknet.sunsetripple`。早期测试版曾用过历史包名 `com.wt.intercom`，两者代码包名与签名都不同，**无法覆盖升级，必须先卸载旧版**。

### 系统拦截安装

来自未知来源的 APK 需要在系统设置里允许对应的安装来源（浏览器 / 文件管理器）。
