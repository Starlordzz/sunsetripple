布局重构

  • 纵向滚动整体废弃，导航 = 横向展卷（题首 / 水岸 / 残波三段）
  • 附近房间是一叶叶泊岸小舟，扫描时水面持续向外荡涟漪
  • 建房 / 房型 = 画卷落款印章与墨字，无按钮无卡片
  • 成员站在水岸线上，按住水面任意处即 PTT

    • 色彩与质感

  • 焦橘→绯红→灰紫的大面积水彩晕染，打破均匀渐变
  • 纸纹噪点覆盖全屏（multiply 混合），墨色 #33253A 文字
  • 楷体/宋体大字 + 竖排标签，层级全靠留白与浓淡
  • 夜间卷 = 「月下残波」：青灰 + 银白月轮

    • 动效与状态

  • 转场 = 展卷：水平位移 + 晕染遮罩擦除
  • 说话 = 脚下涟漪晕开，消息到达 = 墨迹在卷上洇开
  • 空状态 = 「附近无舟」，一行小字 + 空水面
  • 代价提示：导航模型改为横向 Page 结构，工程量五案最大
